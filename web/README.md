# Hima: web app

The landing site (`/`) and the hot-seat game (`/play`). Next.js 16, built as a static export. See the [root README](../README.md) for the project overview.

```bash
pnpm install
pnpm dev          # http://localhost:3000
pnpm build        # static site in ./out
```

## Design system: "Spruce & Ember"

| Token | Hex | Used for |
|---|---|---|
| `ink` | `#07110f` | page background (near-black spruce) |
| `glacier` | `#9fe7d4` | primary: shares, honest signers, CTAs |
| `ember` | `#ff7a45` | signal: cheaters, warnings |
| `brass` | `#e8b65a` | the group key only (a nod to Zcash gold) |
| `bone` | `#eee9df` | text, and the single light section |
| `moss` | `#8da59d` | secondary text |

Type: Instrument Sans, Instrument Serif italic, JetBrains Mono.

## Layout

- `src/lib/frost/`: typed client over frost-wasm. `pkg/` is generated by `crates/frost-wasm/build-wasm.sh`.
- `src/lib/game/engine.ts`: protocol steps for each level.
- `src/components/game/`: game screens and protocol log.
- `src/components/hero/`: landing page 3D scene (illustration only).
- `src/lib/site.ts`: links and status copy.
